# SSH Конструктор / SSH Constructor

Кроссплатформенное приложение (Linux, Windows, Android): подключается к серверу или роутеру по SSH
и рисует интерфейс (кнопки, поля, полосы, список служб) по простому текстовому описанию (YAML).
Программировать не нужно. Справка по формату описания есть внутри приложения.

A cross-platform app (Linux, Windows, Android) that connects to a server or router over SSH and builds
its UI (buttons, fields, progress bars, service list) from a simple YAML description. No coding needed.
Format help is built into the app.

## Возможности
- Избранные серверы (имя, хост, порт, пользователь). Пароли нигде не сохраняются.
- Проверка отпечатка ключа сервера, IPv4 и IPv6 (в том числе Yggdrasil, Mycelium), свой DNS необязателен.
- Страницы из YAML: поля, кнопки, цепочки команд с запасными вариантами, полосы, подтверждения.
- Список служб OpenWrt: автозапуск, старт, перезапуск, перезагрузка конфига, стоп, kill, CPU, RAM, PID.
- Кнопка перезагрузки: приложение само ждёт устройство и переподключается.
- Языки из файлов `src/lang/*.json` (можно добавить свой), светлая и тёмная тема по настройкам системы.

## Как получить установщики
1. Загрузите все файлы в репозиторий GitHub (ветка main). Папка `.github` скрытая, не потеряйте её.
2. Вкладка Actions, «Сборка», Run workflow.
3. Скачайте файлы из Artifacts: linux-deb-appimage (`.deb`, `.AppImage`, `.rpm`), linux-flatpak, windows-exe, android-apk.

## Реклама
В приложение встроены рекламные баннеры (папка `src/ads`, список в `src/ads.js`). Они лежат внутри
программы, не загружаются из интернета, подписаны словом «Реклама» и ничего не отслеживают.
В YAML-описаниях их изменить нельзя. Проект открытый (MIT): форк может убрать баннеры.
